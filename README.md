# Portafolio Académico · Daniel Vaca

Portafolio académico interactivo en forma de **cielo estrellado**: cada estrella es una materia y su constelación son los proyectos. Cada proyecto enlaza a su propio repositorio.

🔗 **Sitio en vivo:** https://danielv-13.github.io

## Cómo está organizado

El portafolio se navega como un universo: **Periodo → Materia (estrella) → Proyectos (constelación)**.

```
DanielV-13.github.io/
├── index.html                          ← Portafolio interactivo (página principal)
├── README.md                           ← Este archivo
└── 2026-1 - Lenguajes de Programación/ ← Índice de la materia (proyectos enlazados)
```

> Cada proyecto vive en su **propio repositorio independiente**. Este sitio actúa como índice y vista previa.

## Cómo añadir contenido

Para agregar materias o proyectos, edita el objeto `PORTFOLIO` al inicio del `<script>` en `index.html`. La estructura es periodos → materias → proyectos, con la URL del repositorio de cada proyecto.
